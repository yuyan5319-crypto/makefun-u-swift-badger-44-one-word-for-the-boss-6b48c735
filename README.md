One word for the boss: **Rescheduler**.

Every office has one — the boss whose signature move is never keeping the
original time. The meeting was Tuesday, then Thursday, then "let's circle
back next week". One word, no phrase, no caption, no explanation: it lands
on its own, catches a real boss habit every colleague recognises, and is not
the first word anyone reaches for.

## Run it

```sh
python3 main.py
```

Writes `Rescheduler` (11 characters, one word) to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), validates
the one-word rule in code, and reads the file back to confirm what was
written is exactly what gets judged. Stdlib only — no third-party packages.
